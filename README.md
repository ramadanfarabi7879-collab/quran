> **منظومة تعليمية متكاملة لإدارة الحلقات القرآنية الافتراضية، ومكالمات الفيديو المباشرة، والمصحف التفاعلي بتقنية "التسميع المغلق" الصارم.**

---

## 🌟 نظرة عامة على المشروع

تم بناء هذه المنصة لتعمل كأكاديمية إلكترونية متطورة وقابلة للإنتاج والإطلاق المباشر. تتيح للمعلم التحكم الكامل بالبث والتسميع ومزامنة المصحف لطلابه في الوقت الفعلي (Realtime) دون الحاجة لأي برامج خارجية.

## 🎯 المزايا الأساسية المنفذة

### 1. المصحف التفاعلي والتحكم الصارم بالتسميع
* **الوضع الأول (عرض المصحف):** مزامنة فورية للصفحة والسورة من المعلم لجميع الطلاب، مع إمكانية السماح بالتصفح الحر أو قفله.
* **الوضع الثاني (التسميع المغلق - Tasmee' Locked Mode):**
  - عند ضغط المعلم على زر **"بدء التسميع المغلق"**، يُحجب المصحف الشريف فوراً من شاشة الطالب وتظهر شاشة التسميع المعتمدة.
  - الحجب مطبق ومؤمن على مستوى الخادم (`HTTP 403 Forbidden`) في واجهات الـ API بحيث يستحيل الالتفاف عليه أو فتح علامات تبويب متعددة أو تحديث الصفحة.
  - واجهة المعلم تعرض عداد الأخطاء والتنبيهات ومؤقت التسميع وتقييم التجويد.
* **الوضع الثالث (العرض الموجّه):** ينقر المعلم على أي آية ليتم تظليلها بالذهب وتوجيه أعين الطلاب إليها مباشرة.

### 2. الفصول الافتراضية ومكالمات الفيديو المدمجة
* غرفة فيديو مدمجة بالكامل تعمل داخل المنصة (كاميرا، ميكروفون، مشاركة شاشة، رفع اليد، كتم الصوت).
* شاشة منقسمة تعرض الفيديو والمصحف التفاعلي جنباً إلى جنب.
* إشعار لحظي (Realtime SSE) لجميع الطلاب فور بدء المعلم للجلسة.

### 3. إدارة الحلقات والطلاب والغياب
* إضافة وتعديل الحلقات بمواعيد متكررة ومستويات مختلفة (مبتدئ، متوسط، متقدم، إجازات).
* قبول ورفض طلبات الانضمام مع كتابة السبب.
* نقل الطالب من حلقة لأخرى، والإيقاف المؤقت، وسلة مهملات الطلاب المحذوفين مع إمكانية الاسترجاع بضغطة زر.
* سجل حضور وغياب مفصل بوقت الدخول الدقيق واعتماد المعلم، مع تصدير التقارير إلى **Excel (CSV)** وطباعة **PDF**.

### 4. التكليفات والواجبات الصوتية
* تعيين سور وآيات الحفظ والمراجعة بمواعيد استحقاق.
* **مسجل صوتي رقمي مدمج في متصفح الطالب** يتيح له تسجيل التسميع المنزلي وسماعه ثم تسليمه للمعلم.
* تصحيح الواجبات ورصد الدرجات والملاحظات التوجيهية.

### 5. سجل الحفظ والتقييم الرقمي
* توثيق إنجازات الطالب التراكمية (الأجزاء والآيات المتقنة).
* مؤشرات بيانية لتوزيع الطلاب ومستويات إتقان التجويد.

### 6. المكتبة والتسجيلات وإعدادات المنصة
* مكتبة إسلامية مع قارئ PDF مدمج وتصنيفات (نور البيان، التجويد، الفقه، التفسير).
* مكتبة تسجيلات الحلقات مع سياسات الحفظ التلقائي (7، 30، 60، 90 يوماً).
* لوحة تحكم لتعديل **اسم المنصة وهويتها البصرية** مباشرة من لوحة الإدارة.

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** Next.js 14 (App Router) + TypeScript + Tailwind CSS.
* **الخطوط والهوية:** خطوط عربية أصيلة (`Cairo`, `Amiri`, `Traditional Arabic`) بتنسيق RTL كامل وتصميم إسلامي راقٍ وأوضاع نهارية وليلية (Dark/Light Mode).
* **قاعدة البيانات (Database):** Prisma ORM مع SQLite محلي (`prisma/dev.db`) جاهز للعمل مباشرة ومهيأ للتحويل لـ PostgreSQL عبر تغيير `DATABASE_URL`.
* **المزامنة اللحظية (Realtime):** Server-Sent Events (SSE) مدمجة + Broadcast Engine للاتصال الفوري منخفض التأخير بين المعلم والطلاب.
* **الفيديو والصوت:** WebRTC API + HTML5 MediaRecorder API للتسجيل الصوتي المباشر.

## 💻 طريقة التشغيل والبدء

```bash
# 1. تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
npm.cmd install

# 2. مزامنة قاعدة البيانات وزرع البيانات التجريبية
npx.cmd prisma db push
npx.cmd tsx prisma/seed.ts

# 3. تشغيل خادم التطوير
npm.cmd run dev
```

افتح المتصفح على: `http://localhost:3000`
